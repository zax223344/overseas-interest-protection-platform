# 公文格式规范：GB/T 9704-2012《党政机关公文格式》（国家标准权威版）

> 本文件取代《智库报告写作要求指南》中「三、格式体例要求」一节（智库指南的字号边距体系仅适用于智库报告，不适用于公文）。
> 智库指南的其余部分（结构表达、对策建议三要素、数据可追溯、三遍打磨法）仍然有效。

## 1. 用纸与版面（标准第 5 章）

- 用纸：A4 型（210mm×297mm）
- 天头（上白边）：37mm±1mm
- 订口（左白边）：28mm±1mm
- 版心：156mm×225mm（推算 CSS 打印边距：上 37mm、下 35mm、左 28mm、右 26mm）
- 一般每面排 22 行，每行排 28 个字，撑满版心
- 文字颜色均为黑色（发文机关标志为红色）

## 2. 字体字号与行距（标准 5.2 / 7.3）

| 要素 | 规范 |
|---|---|
| 公文格式各要素默认 | 3 号（16pt）仿宋_GB2312（fallback: 仿宋/FangSong） |
| 数字与英文 | 半角 3 号 Times New Roman |
| 行距 | 固定值 28~29 磅（实现每面 22 行；不是 1.5 倍行距） |
| 总标题（发文标题） | 2 号（22pt）小标宋体（fallback: 华文中宋 STZhongsong / 宋体加粗），红色分隔线下空二行居中；多行时词意完整、梯形或菱形排列 |
| 一级标题「一、」 | 3 号黑体（不加粗，黑体本身醒目） |
| 二级标题「（一）」 | 3 号楷体（不加粗） |
| 三级「1.」四级「（1）」 | 3 号仿宋（可加粗） |
| 正文 | 3 号仿宋，每个自然段左空二字（首行缩进 2 字符），回行顶格 |
| 结构层次序数 | 依次用「一、」「（一）」「1.」「（1）」 |

## 3. 公文格式三部分（标准 7.1）

### 版头（首页红色分隔线以上）
- 发文机关标志：发文机关全称/规范化简称 +「文件」（或仅全称），红色小标宋体居中，上边缘至版心上边缘 35mm
- 发文字号：3 号仿宋居中，发文机关标志下空二行；年份用六角括号〔2026〕，顺序号不加「第」不编虚位（如 或智〔2026〕12 号）
- 红色分隔线：发文字号之下 4mm，与版心等宽

### 主体
- 标题：2 号小标宋，红色分隔线下空二行居中
- 主送机关：标题下空一行，居左顶格，最后一个机关名称后标全角冒号
- 正文：3 号仿宋，主送机关下一行；**公文首页必须显示正文**
- 附件说明：正文下空一行左空二字，「附件：1.XXX」，名称后不加标点
- 发文机关署名 + 成文日期：成文日期右空四字；署名以成文日期为准居中（无印章时署名右空二字、日期再右移）
- 成文日期数字：阿拉伯数字年月日标全，**月日不编虚位**（2026年9月2日，不是 09月02日）

### 版记（末页）
- 抄送机关：4 号仿宋，印发机关上方一行，左右各空一字，「抄送：」后全角冒号
- 印发机关和印发日期：4 号仿宋，印发机关左空一字、日期右空一字，后加「印发」二字
- 分隔线：首条末条粗线（0.35mm），中间细线（0.25mm），与版心等宽

## 4. 页码（标准 7.5）

- 4 号半角宋体阿拉伯数字
- 数字左右各放一条一字线，如「— 1 —」（不是「-1-」）
- 位于版心下边缘之下，一字线距版心下边缘 7mm
- 单页码居右空一字，双页码居左空一字（HTML 打印可简化为单双页外侧对齐；web 渲染一律居右可接受）

## 5. 其他

- 标点符号用法遵循 GB/T 15834，数字用法遵循 GB/T 15835
- 横排表格：单页码表头在订口一边，双页码表头在切口一边
- 简报类信息参考公文主体格式（标题/层次序数/正文字体字号/版心页码），版头可简化为简报标志，不强求发文字号与印章
