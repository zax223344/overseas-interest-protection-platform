⚙️ 操作

📖 使用说明

  1. 将本文件放入项目根目录 (与 index.html 同级)
  2. 通过项目首页访问本页面 (需同域访问 localStorage)
  3. 点击 "导出 JSON 文件" 下载数据备份
  4. 将下载的 JSON 文件保存为 server/data.backup.json
  5. 在服务器上运行: cd server && node scripts/import-data.js
